# CSGO-SKINS Inspector: Releases

Instalador oficial do **CSGO-SKINS Inspector**, a extensão de navegador que coloca em cada skin do [csgo-skins.com](https://csgo-skins.com) os botões **Inspecionar no CS2** (abre o jogo com a skin, no desgaste certo) e **Ver no Mercado da Steam** (com o preço em R$).

**[Baixar o instalador mais recente](https://github.com/cesarkali/csgo-skins-inspector-releases/releases/latest/download/CSGO-SKINS-Inspector-Setup.exe)**

## Como usar

1. Baixe e rode o `CSGO-SKINS-Inspector-Setup.exe` (Windows).
2. Siga o guia do instalador para adicionar a extensão ao seu navegador. Os navegadores só deixam fazer isso à mão, uma vez, pelo modo do desenvolvedor.
3. Pronto: a extensão se atualiza sozinha. O instalador deixa uma tarefa que confere versões novas a cada 3 horas.

Para o botão do CS2 funcionar, a Steam e o Counter-Strike 2 precisam estar instalados.

Mais informações no site: [csskins.caliberda.com.br](https://csskins.caliberda.com.br).

## Sobre este repositório

Aqui ficam só os arquivos publicados de cada versão, na aba [Releases](https://github.com/cesarkali/csgo-skins-inspector-releases/releases):

- `CSGO-SKINS-Inspector-Setup.exe`: o instalador, com a extensão embutida.
- `CSGO-SKINS-Inspector.zip`: a extensão, baixada pelo atualizador automático.

O código-fonte é privado. Não é um produto oficial da Valve nem do csgo-skins.com.
